# DATA110 Laboratory Exercises

This folder is reserved for the student's laboratory exercises and should contain the original completed lab files required by the course.

The available course material confirms practice and laboratory coverage of topics including:

- data cleaning and missing-value imputation
- exploratory data visualization
- Logistic Regression
- Gaussian Naive Bayes
- K-Nearest Neighbors
- Decision Trees
- Random Forest concepts
- Support Vector Machines
- PCA
- K-Means / clustering
- neural-network fundamentals

**Important:** this index does not invent or replace individual lab submissions. Add the actual completed lab notebooks/scripts here before final submission if they were submitted separately in the course portal.
