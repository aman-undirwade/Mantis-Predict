# Assignments and Practice Work

Place completed DATA110 assignments, practice notebooks, and exercise scripts in this folder. Keep one task per file or subfolder and use descriptive names.

Recommended naming pattern:

```text
01_data_cleaning/
02_eda_visualization/
03_logistic_regression/
04_naive_bayes/
05_knn/
06_decision_tree/
07_svm/
08_pca/
09_kmeans/
10_neural_networks/
```

The advanced predictive-maintenance project is intentionally kept separate under `src/`, `results/`, and the other capstone folders.

**Do not upload fabricated coursework.** The repository should contain the student's actual completed work for these sections.
