# Mantis-Predict

This repository contains the Mantis Predict website plus the **DATA110 Capstone** submission.

## DATA110 Capstone

The complete advanced-project documentation and reproducible implementation are in:

**[`DATA110-Capstone/`](DATA110-Capstone/)**

The capstone is an aircraft-engine predictive-maintenance study using NASA C-MAPSS FD004. It compares classical DATA110 machine-learning models, evaluates explicit warning horizons, uses engine-aware validation, selects an operating threshold, evaluates the official test set, and documents SHAP-based explainability.
